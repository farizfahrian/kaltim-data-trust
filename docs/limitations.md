# Limitations & Responsible Interpretation

1. **Bukan sistem resmi pemerintah:** Proyek ini merupakan prototipe riset independen untuk pembuktian rekayasa kualitas data publik, bukan sistem operasional Pemerintah Provinsi atau Diskominfo Kalimantan Timur.
2. **Cakupan fasilitas kesehatan 2024:** Karena URL katalog fasilitas kesehatan gabungan tahun 2023–2025 mengembalikan `HTTP 404` pada saat audit (18 November 2026), metrik `facility_total_count` dibatasi secara eksplisit pada **Rumah Sakit + Puskesmas Induk** (`47 + 188 = 235` fasilitas). Klinik pratama swasta, praktik mandiri, dan apotek tidak diklaim termasuk di dalamnya.
3. **Definisi baris "Dokter" pada `SRC-DOC`:** Meskipun deskripsi katalog CKAN tidak menyebut dokter gigi pada poin pertama, formula sel Excel `=SUM(F4:F7)` pada file resmi menjumlahkan `Dokter Umum + Dokter Spesialis + Dokter Gigi + Dokter Gigi Spesialis` (setara *Tenaga Medis* Permenkes 18/2022). Oleh sebab itu, proyek ini menyediakan baik `doctor_total_count` (Tenaga Medis Kedokteran) maupun `doctor_general_count` / `doctor_general_per_100k` secara terpisah.
4. **Selisih agregat Dokter Spesialis 2024:** Penjumlahan 10 kabupaten/kota menghasilkan `930` orang sedangkan baris agregat provinsi pada sumber mencatat `980` orang (`+50`). Sistem tidak mengubah angka sumber secara sepihak, melainkan memberi penanda `warning` (`DQ-011`) pada angka provinsi.
5. **Batas interpretasi rasio per kapita:** Rasio tenaga medis atau fasilitas per 100.000 penduduk adalah ukuran kepadatan administratif, bukan ukuran langsung kualitas klinis, waktu tunggu, ataupun jarak tempuh geografis (terutama pada kabupaten berpenduduk jarang namun berwilayah luas seperti Mahakam Ulu, Berau, dan Kutai Timur).
6. **Status lisensi sumber:** Paket CKAN pada Satu Data Kaltim belum mencantumkan pengenal lisensi terbuka formal (`license_id` kosong), sehingga repositori ini tidak mendistribusikan ulang file `.xlsx`/`.csv` mentah.
